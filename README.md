# Cura Care

Responsive, framework-free cosmetics and personal-care storefront concept.

## Run

Open `index.html` directly, or serve the folder with any static local server.

## Included

- Cura Care brand identity and supplied logo
- Twelve shopping categories
- Responsive category and product grids
- Category filtering
- Wishlist feedback
- Persistent localStorage shopping bag
- Mobile navigation and cart drawer
- Newsletter interaction

The mock catalogue lives in `assets/js/data.js`, ready to be replaced by backend data later.
